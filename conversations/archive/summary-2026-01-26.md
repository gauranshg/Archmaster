## Technical Decisions

### Why React 19?
- Starter Kit uses React 19 (newer than spec's React 18)
- Better performance and features
- Future-proof

### Why Zustand?
- Lightweight (~1KB)
- Simple API, no boilerplate
- Built-in persist middleware
- Excellent TypeScript support

### Why Dexie?
- Type-safe IndexedDB wrapper
- Promise-based API
- Excellent documentation
- Built-in transaction support

### Why React Flow?
- Built specifically for node diagrams
- Native React support
- Custom node components
- Great performance (100+ nodes)
