# Verification Guide: `azd up`

**Objective:**
To verify that the `azd` Infrastructure as Code (IaC) files correctly provision all necessary Azure resources and deploy the application components.

**Prerequisites:**
1.  You have cloned the project repository and are on the correct branch (`feature/add-azd-support` or `main` after merge).
2.  You have completed the human-led scaffolding steps to create the `src/frontend` and `src/api` directories.
3.  You have successfully logged into your Azure account by running `azd auth login` in your terminal.

---

### Verification Steps

1.  **Navigate to Project Root:**
    Open a terminal or command prompt and navigate to the root directory of this project.

2.  **Run `azd up`:**
    Execute the following command:
    ```bash
    azd up
    ```

3.  **Provide Input:**
    The command will prompt you for the following information. Please provide it as requested:
    *   **Environment Name:** Enter a short, unique name for this deployment (e.g., `saas-dev-verify`). This name will be used as a prefix for your resources.
    *   **Azure Subscription:** Select the Azure subscription you want to deploy to from the list.
    *   **Azure Location:** Select the Azure region where you want to deploy the resources (e.g., `eastus`).

4.  **Wait for Completion:**
    The `azd up` command will now begin provisioning all Azure resources and deploying the code. This process can take several minutes. Please wait for it to complete.

---

### Evidence Required for Verification

For me to verify that the process was successful, please provide the following evidence by pasting it into our chat:

1.  **Full Terminal Log:**
    **This is the most important piece of evidence.** Please copy the *entire* text output from your terminal, starting from the moment you ran `azd up` until the command finished.

2.  **Deployed Endpoint URLs:**
    At the end of a successful run, `azd` will display the URLs for both the frontend and the API. Please copy and paste both endpoint URLs.

3.  **Azure Portal Screenshot:**
    *   Navigate to the [Azure Portal](https://portal.azure.com/).
    *   In the search bar, look for the resource group created by `azd`. The name will be `rg-<your-environment-name>` (e.g., `rg-saas-dev-verify`).
    *   Click on the resource group to view its contents.
    *   Take a screenshot of the list of resources inside this resource group. It should contain resources like a Static Web App, a Function App, a Key Vault, a SQL server, etc.

Once you provide this evidence, I can confirm that the `azd` setup is working correctly and we can proceed with the next development tasks.
