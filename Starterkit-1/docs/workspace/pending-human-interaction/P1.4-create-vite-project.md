# Human Task Guide: Create the Frontend Project

**Objective:**
To create a standard, working frontend application using the official Vite command-line tool. This will serve as the foundation for our starter kit's UI.

**Prerequisites:**
- You have [Node.js](https://nodejs.org/) (LTS version) installed on your machine.

---

### Scaffolding Steps

1.  **Navigate to Project Root:**
    Open a terminal or command prompt and ensure you are in the root directory of this project.

2.  **Run the Vite Creation Command:**
    Execute the following command exactly as written. This will create a new `src/frontend` directory in our project root, pre-configured with a React and JavaScript template.
    ```bash
    npm create vite@latest src/frontend -- --template react
    ```
    *Note: The `--` at the end is important. It separates the arguments for `npm create vite` from the arguments for the `create-vite` script itself.*

3.  **Install Dependencies:**
    Once the command from the previous step is complete, navigate into the new directory and install the necessary packages.
    ```bash
    cd src/frontend
    npm install
    cd ../..
    ```

---

### Evidence Required for Verification

To confirm that the project was created successfully, please provide the following:

1.  **Confirmation Message:** Simply confirm that you have run the commands as described.
2.  **(Optional) Directory Listing:** For extra verification, you can run `ls -R src/frontend` (or `dir /s src\frontend` on Windows) and paste the output. This will show me that the file structure was created correctly.

Once you have completed these steps, I will proceed with the next tasks.
