# Human Task Guide: Create the Backend Project

**Objective:**
To create a standard, working backend Function App project using the official Azure Functions Core Tools. This will serve as the foundation for our starter kit's API.

**Prerequisites:**
- You have the [Azure Functions Core Tools](https://learn.microsoft.com/en-us/azure/azure-functions/functions-run-local) installed on your machine.
- You have [Python](https://www.python.org/downloads/) (3.9+) installed.

---

### Scaffolding Steps

1.  **Navigate to Project Root:**
    Open a terminal or command prompt and ensure you are in the root directory of this project.

2.  **Run the Function App Creation Command:**
    Execute the following command exactly as written. This will create a new `src/api` directory in our project root, pre-configured as a Python function app.
    ```bash
    func init src/api --worker-runtime python --language python
    ```
    This command initializes a project in the `src/api` folder for the Python runtime.

3.  **Create a Sample Function:**
    To ensure the project is fully functional for `azd`, let's create a sample HTTP trigger function.
    ```bash
    cd src/api
    func new --name HttpExample --template "HTTP trigger" --authlevel "anonymous"
    cd ../..
    ```
    This creates a new function named `HttpExample` that can be called anonymously.
